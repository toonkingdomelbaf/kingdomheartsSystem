# Wipe and Recycle

A Windows automation that securely deletes files and folders from a selected directory and moves them to the Recycle Bin.

## Project Layout

Run the automation from this Code directory. The project files and supporting modules are contained alongside this README.

## Usage

Review the Python entry points in this directory and run the appropriate script or executable from Windows.

## Description

A Windows automation that securely deletes files and folders from a selected directory and moves them to the Recycle Bin.

## Purpose

Remove unwanted files and folders safely from the selected directory.
